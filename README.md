# 📘 1行日記 - One Line Diary (Laravel 12)

Laravel 12 で構築されたシンプルな日記投稿サイトです。  
画像付きで1行の日記を投稿・編集・削除・一覧表示できます。

---

## 📦 機能一覧

- 日記の新規投稿（画像付き）
- 投稿済み日記の編集・削除
- 一覧ページに5件ずつページネーション
- 日記ごとに1枚の画像（JPG）アップロード
- 一覧ページに画像サムネイル表示
